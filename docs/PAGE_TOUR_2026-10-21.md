# ChombuTar · First-visit Page Tour

## Behavior

The first visit to each **major signed-in screen** opens one short, clean guide:
1. **Got it** marks only the current screen as explained. It will not appear again during normal revisits or reloads.
2. **Don't show me again** turns off **all** page explanations for that account on the current device, including future screen visits.
3. **Settings → Account → Page introductions → Restart page tour** clears the seen-page list and global opt-out, then opens Showroom so the explanations can be replayed.

The guide is centralised in `src/components/PageTour.jsx` and `src/lib/pageTour.js`. It lives in the protected `Layout`; authentication/landing screens, individual cards, galleries, pop-up dialogs, and detail modals do not trigger additional tour steps.

## Privacy and persistence

The account-scoped storage key is `chombutar:page-tour:v1:<user id>`. Only `disabled` (boolean) and an array of `seen` screen IDs are stored in the browser's localStorage. This does not store personal profile data, chat content, or payment information.

No database migration, network request, provider secret or admin setting is required. The setting persists after page reloads and across sign-in sessions **in the same browser/device**. It does *not* currently synchronize across multiple devices, and clearing browser storage resets it.

A blocked/unavailable browser storage falls back to in-memory behavior for the tab; no crash is allowed.

## UI and accessibility

- Centered responsive white popup with a concise heading, page summary and one helpful next action.
- Focus goes to **Got it**; Tab stays within the two buttons.
- Escape is equivalent to acknowledging the current screen, not disabling the whole tour.
- The foreground uses `role=dialog`, `aria-modal=true`, a meaningful title and descriptive text.
- Prevent page scroll while the dialog is open; restore focus after dismissing it.
- Backend/API services, payments, wallet operations and permissions are not modified.
- Existing Playwright suites use a returning-subscriber fixture that already opted out; `tests/page-tour-ui.mjs` exercises the true first-visit state at 390px and 1280px, per-page dismissal, global opt-out, separate accounts and restart.
